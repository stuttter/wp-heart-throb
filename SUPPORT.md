# Support

Use the [WordPress.org support forum](https://wordpress.org/support/plugin/wp-heart-throb/)
for installation and usage questions. Use the GitHub issue tracker for
reproducible defects and narrowly scoped enhancements.

Report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/stuttter/wp-heart-throb/security/advisories/new),
not in a public issue.
